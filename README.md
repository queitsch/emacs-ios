# emacs-ios

GNU Emacs for iPhone, a fork of [emacs-ipad](https://codeberg.org/mclearc/emacs-ipad).

The source lives on Codeberg: https://codeberg.org/queitsch/emacs-ios (branch `iphone`). Upstream's history carries files over GitHub's 100 MB limit, so it can't be mirrored here.

Test builds: add `https://jes.moe/alt/source.json` as a source in AltStore Classic or SideStore.
